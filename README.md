# Panel LED

Simula un letrero de LED con un mensaje que se desplaza por la pantalla.

- **Android (Kotlin):** `app/` — vista propia (`LedView`) que dibuja cada LED en un Canvas, pantalla completa y siempre encendida; tocar la pantalla cambia el color de las letras.
- **Escritorio (HTML + JavaScript):** `escritorio/panel-led.html` — la misma idea en el navegador, sin instalar nada.
